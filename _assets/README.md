# _assets/

Drop AEGIRA brand files here. Expected (Variante a):

- `aegira_logo.svg`         — full-color
- `aegira_logo_dark.svg`    — dark-mode (light text)
- `aegira_logo_mark.svg`    — symbol only (favicon, plugin icon, lock-screen)
- `aegira_logo_1024.png`    — square PNG, 1024×1024
- `moodboard.pdf` OR `moodboard.png` — for color/typography token extraction

Once present, the BRAND.md and the favicon set are auto-generated from these.
