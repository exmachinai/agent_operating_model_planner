## PHASE P0 — Schema-Treue & Lesbarkeit (blockierend)

- **P0.1 PVM-Code-Legende sichtbar** — `components/PlanViews.tsx`. Code→Bedeutung jetzt
  als umbrechende Chip-Legende unter der Matrix (kein reiner Hover mehr), mobiltauglich.
- **P0.2 Hook-Schema kanonisch** — `templates.hook_files()` erzeugt ausführbare
  Command-Hooks (`*.sh`): `constitution-guard` (PreToolUse, `permissionDecision:"deny"`),
  `audit-log` (PostToolUse, append-only), `stop-on-red` (PostToolUse, `continue:false`),
  `checkpoint` (Stop). Registrierung in `settings.json` unter `hooks` (Event → matcher →
  command). Blockieren via Exit-Code 2 / Deny-JSON.
- **P0.3 settings.json schematreu** — Phantasie-Keys (`thinking_budget`, `*_path`,
  `log_level`, alte `$schema`-URL) entfernt. Nur dokumentierte Felder; `permissions`
  deny→ask→allow; korrektes `$schema` (json.schemastore.org).
- **P0.4 Schema-Validierungs-Gate** — `app/harness/schema_check.py` (hinterlegtes Schema)
  + `tests/test_harness_schema.py`. Prüft settings/Hooks/Agenten-Frontmatter/plugin.json/
  .mcp.json; absichtlich falsche Felder → rot (CI-Gate).
- **P0.5 iPhone Safe-Area** — `layout.tsx` (`viewportFit:"cover"`), `tokens.css`
  (`max(clamp(...), env(safe-area-inset-*))` an `.aegira-shell`; sticky Bottom-Bar mit
  `env(safe-area-inset-bottom)`).

## PHASE P1 — Vollständigkeit, Trust, Mobile

- **P1.1/A4** Eine Schema-Version (`compiler._SCHEMA_VERSION`); Changelog/Compiler/
  `package.json` (0.9.0)/runtime_requirements konsistent.
- **P1.2/B1** `.mcp.json` aus `CatalogSkill.required_mcps` (Transport http/stdio,
  Secrets nur `${ENV}`) — nur wenn ein Skill einen Server verlangt.
- **P1.3/B3** Permission-Modi + `ask`-Liste, an Reifegrad gekoppelt; Protected Paths.
- **P1.4/B4** Befehle → Skills (Slash-only via `disable-model-invocation`);
  `plugin.json` ohne doppeltes `commands`-Manifest; `.claude/commands/` nur Legacy-Hinweis.
- **P1.5/C1** Autonomie-/Reifegrad-Selektor (Stufe 1–4): `AutonomyLevel`, Revise-Kommando
  `autonomy`, UI-Selektor (Harness-Seite). Stufe steuert `defaultMode`, `ask`-Dichte,
  Telemetrie. Prinzip: Autonomie an Reversibilität (BP-MD §7).
- **P1.6/C2** `ToolSpec.irreversible` → erzwingt HITL-Knoten (z. B. `trigger_deploy`).
- **P1.7/C3** Credential-/Transcript-Hygiene: deny `Read(./.env)` + Secret-Globs;
  `cleanupPeriodDays`, `CLAUDE_CODE_SKIP_PROMPT_HISTORY` in settings/env.example.
- **P1.8/D2 + P1.9/D3** RACI-Anzeige (Standard) ⇄ PVM-Toggle; Konsistenz-Labels auf RACI
  gemappt (genau ein Accountable, ≥1 Responsible) — interne Rules unverändert.
- **P1.10–P1.13** Mobile/A11y: sticky erste Spalte + Scroll-Hinweis, ≥44px Targets,
  16px-Inputs (kein iOS-Zoom), sticky Bottom-Bars, ARIA-Rollen (radiogroup/radio),
  Status nicht nur über Farbe (✓ ok / ⚠ prüfen).
